## Основные команды 

1. git init инициализировать репозиторий 
2. git add добавить файлы для следующего коммита (кароче какая-то жуть, по факту я этой командой говорю гиту, возьми текущий файл и подготовь ее для коммита.) Есть еще такое понятие как Staging area - грубо говоря место, где я выбираю какие изменения попадут в некст коммит. Например я делаю параллельно 3 мд файла, а хочу закоммитить только один. Я должен сделать гит адд (нужный файл) и дальше коммитить пушить. Либо по очереди все три файла так лупить по три команды, чтобы типо было красивенько. И че круто. если я хочу сразу три файла закоммитить как мужчина я просто луплю *git ad .* и все три файла готовы к коммиту ещкере. 

3. git commit Зафиксировать изменения (отличается от git push, тем что сохраняет изменения локально на моем компе)
4. git push отправить коммиты в репозиторий 
5. Забрать изменения из репозитория (насколько я понял, если прописал пуш т.е разместил изменения в репозитории, можно их от туда забрать и их там не будет)

**git chekout** команда которая позволяет переключаться между ветками (branch), да и дохуя че она делает. Чат ГПТ говорит что нынче в моде команда git switch

* git switch -c develop создание новой ветки и переключение на нее 
* git restore filе.txt восстановление файла 

**git merge** - соединяет ветку с той, в которой я нахожусь. Например: 
* Чекаю ветку в которой я нахожусь git branch
