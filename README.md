## Основные команды 

1. git init инициализировать репозиторий 
2. git add добавить файлы для следующего коммита 
3. git commit Зафиксировать изменения (отличается от git push, тем что сохраняет изменения локально на моем компе)
4. git push отправить коммиты в репозиторий 
5. Забрать изменения из репозитория (насколько я понял, если прописал пуш т.е разместил изменения в репозитории, можно их от туда забрать и их там не будет)
